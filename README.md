# Portfolio — Michaël Belval

Landing page portfolio (fichier unique `index.html`, sans dépendance ni build).

## Publier avec GitHub Pages
1. Settings → Pages → Source : « Deploy from a branch »
2. Branche : celle qui contient `index.html`, dossier `/ (root)`
3. Le site est en ligne sur `https://<utilisateur>.github.io/<repo>/`

Fonctionne aussi tel quel sur Netlify, Vercel ou tout hébergement statique.
